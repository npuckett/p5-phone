Tag Taxonomy

Capability Tags

These describe what the sketch uses or demonstrates. They can filter to pages of related examples.

  • Inputcamera, microphone, motion, touch, speech, NFC
  • Outputsound, vibration, torch, screen, haptics
  • Techniqueml5, facemesh, handpose, bodypose, color, tracking

Platform Tags

These should be consistent, high-level filters for support expectations.

  • iOS + AndroidWorks broadly on current mobile browsers, subject to permission prompts.
  • AndroidRequires Android browser support, such as NFC, vibration, or torch workflows.
